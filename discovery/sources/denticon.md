## Problema que resuelve

Grupos y DSOs que crecen con sistemas mono-sede y pilas de vendors necesitan DentalOS® cloud centralizado (PMS + imagen + pagos + engagement + analytics) para estandarizar, centralizar y escalar. Referencia enterprise multi-sede; excesivo para consultorio argentino chico.

### 1. Identificación
Producto Denticon (suite DentalOS®: Cloud 9 ortodoncia, Apteryx imagen, Pay, MyTooth), empresa Planet DDS, Irvine, California (desde 2003, 448 empleados). URLs oficiales arriba.
### 2. Segmento objetivo
DSOs y grupos dentales (1–300+ sedes); planes Essentials (1–2), Pro (3–19), Enterprise (20+); +13.000 prácticas.
### 3. Modalidad
SaaS cloud multi-sede con base centralizada, API abierta (DentalOS™), IA Pearl; sin servidor.

## Features detectadas

PMS centralizado (ledger, scheduling multi-sede, cross-location); imagen cloud Apteryx 2D/3D con IA Pearl (AI Assist add-on); pagos integrados (Stripe enterprise, text-to-pay, surcharge); comunicaciones (recordatorios, 2 vías, MyTooth formularios/scheduling); elegibilidad de seguros en tiempo real; eClaims ilimitados + attachments (DentalXChange); analytics (Morning Huddle, dashboards, producción, aceptación, Data Share); Launchpad para grupos nacientes; agentes IA DentalOS (2026, early access).
